# Week 2 – Backend Development (Node.js, Express.js, MongoDB)

| Folder | Task |
|---|---|
| [`todo-api`](./todo-api) | Assignment 1 – To-Do List REST API |
| [`auth-api`](./auth-api) | Assignment 2 – User Authentication API (bcrypt + JWT) |
| [`notes-app-backend`](./notes-app-backend) | Mini Project – Notes App Backend (CRUD + JWT-secured routes) |

Each folder is an independent project. Inside a folder run `npm install`, copy `.env.example` to `.env`, then `npm run dev`. See each folder's README for endpoints.

**Topics covered:** Node.js & NPM, Express routing, MongoDB + Mongoose, REST design, JWT + bcrypt authentication.
